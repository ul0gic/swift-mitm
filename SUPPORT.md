# Support

Use [GitHub Issues](https://github.com/ul0gic/swift-mitm/issues) for reproducible defects and documentation problems. Include the SwiftMITM revision or tag, macOS and Swift versions, protocol path, expected behavior, actual behavior, and a minimal reproduction that contains no sensitive traffic or credentials.

Use [GitHub Discussions](https://github.com/ul0gic/swift-mitm/discussions) for integration questions when Discussions is enabled. SwiftMITM is pre-1.0 software; support is best-effort and public API changes follow Semantic Versioning once releases begin.

Report security-sensitive findings through [SECURITY.md](SECURITY.md), never through a public issue.
